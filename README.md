# Mesclador de PDFs

Um script simples em Python para automatizar a junção de múltiplos arquivos PDF em um único documento final de forma ordenada.

## 🚀 Como Usar

1. Crie uma pasta chamada `arquivos` no mesmo diretório do programa.
2. Coloque dentro dela todos os arquivos PDF que deseja mesclar.
3. Execute o programa. O arquivo unificado será gerado com o nome `arquivo_final.pdf`.

## 🛠️ Tecnologias Utilizadas
* Python 3
* PyPDF2
* Salve o arquivo
